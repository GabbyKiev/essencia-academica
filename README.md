# Essência Acadêmica
![Prévia do site Essência Acadêmica](assets/preview.png)

### O conhecimento é seu. A voz também.

Site institucional desenvolvido para a **Essência Acadêmica**, uma marca dedicada à revisão, orientação e aprimoramento da escrita acadêmica, valorizando a autoria, o pensamento crítico e a integridade intelectual.

## Sobre o projeto

O objetivo foi criar uma experiência digital que fugisse dos modelos tradicionais de sites acadêmicos, combinando uma identidade visual editorial com navegação intuitiva e comunicação humanizada.

O projeto explora uma estética sofisticada, inspirada no universo literário, com tipografia expressiva, cores naturais e composição visual minimalista.

## Tecnologias utilizadas

- **HTML5** — estruturação semântica das páginas.
- **CSS3** — estilização, identidade visual e layouts responsivos.
- **JavaScript** — interatividade e comportamento dos elementos.
- **Git e GitHub** — versionamento e gerenciamento do código.

## Principais características

- Identidade visual editorial e contemporânea.
- Layout adaptável a diferentes tamanhos de tela.
- Apresentação organizada dos serviços acadêmicos.
- Seção institucional dedicada à fundadora.
- Navegação intuitiva.
- Comunicação orientada à valorização da autoria acadêmica.

## Identidade visual

A proposta visual utiliza tons de creme, oliva, areia, café e terracota.

A combinação entre tipografia serifada, espaços de respiro e elementos gráficos cria uma experiência inspirada em publicações editoriais.

## Serviços apresentados

1. Da Ideia ao Texto.
2. Mentoria em Escrita Acadêmica.
3. Análise de Similaridade e Integridade Acadêmica.
4. Revisão Acadêmica Especializada.
5. Normalização e Normas Acadêmicas.

## Desenvolvimento

Projeto desenvolvido com HTML, CSS e JavaScript, utilizando o Visual Studio Code como ambiente de desenvolvimento e o GitHub para controle de versões.
